// What counts as networking in DocuSpend's own code (decision 0006).
//
// Every project in the repository is compiled with this list (see Directory.Build.targets); using
// anything on it fails the build. Adding an entry is a normal change. Removing one is a change to
// docs/decisions/0006-privacy-approach-and-network-boundary.md. See privacy/README.md.
//
// Format: <documentation ID>;<message shown on a violation>. N: bans a namespace and everything in
// it, including nested namespaces; T: a type; M: one method overload, so each overload is listed.
// A test checks that every entry names a symbol that exists, and that each family of overloads is
// complete. This file must stay named exactly BannedSymbols.txt; the analyzer ignores any other name.
// Messages must not contain a semicolon.
