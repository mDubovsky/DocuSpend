# Native networking that a shipped assembly must not import (decision 0006).
#
# The dependency check (privacy-dependencies) reads every P/Invoke declaration in everything that ships and
# fails on an import from one of these libraries, or of one of these functions from any library (on Linux and
# macOS, sockets live in the C library itself). Adding an entry is a normal change; removing one is a change
# to docs/decisions/0006-privacy-approach-and-network-boundary.md. See privacy/README.md.
#
# Format: "library <name>" or "function <name>", one per line. Library names are matched ignoring case, file
# extension (.dll, .so, .dylib) and a "lib" prefix. Function names are matched ignoring case.
