# Decisions

Short records of non-obvious decisions, one file per decision: `NNNN-short-title.md`. Write one when a choice needs more context than a line in a spec or plan.

Suggested shape:

```
# NNNN: Title

Status: proposed | accepted | superseded by NNNN

## Context
What forced the decision?

## Decision
What we chose.

## Consequences
What this makes easier and harder. Alternatives considered.
```
