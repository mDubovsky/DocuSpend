# Contributing

DocuSpend is built with an AI-assisted workflow: every change starts as an intent, becomes a spec, then a plan, then code. See [docs/sdlc.md](docs/sdlc.md).

1. Propose a change by adding a work item (see [work/README.md](work/README.md)).
2. Wait for the intent and spec to be agreed before implementing.

**Privacy:** never commit real bank statements or other personal financial data. Use synthetic samples in `samples/public/`. `samples/private/` is gitignored for your own local files.
